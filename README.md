# 🚗 Cognos Car Sales Visualization

## 📊 Project Overview

This project focuses on analyzing car sales data and creating interactive visualizations using **IBM Cognos Analytics**.

The objective of the project is to understand car sales performance across different models and identify patterns and trends in the available sales data.

## 🛠️ Tools & Technologies

* IBM Cognos Analytics
* Microsoft Excel
* Data Visualization
* Data Analysis

## 📁 Project Structure

## 📌 Dataset

The project uses an Excel dataset containing car sales information.

The dataset is included in the `dataset` folder for reference and reproducibility.

## 📈 Visualizations

The Cognos dashboard contains visualizations designed to analyze:

* Profit_Quantitysold_averagequantitysold
* profitbydealerid
* quantitysoldbymodel
* sales_Dashboard
* service_dashboard
